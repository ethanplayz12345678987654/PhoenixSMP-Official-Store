# PhoenixSMP Official Store

This repository contains a simple static website for the PhoenixSMP store showcasing 5 Minecraft ranks.

Files added:
- index.html — main page with 5 rank cards
- styles.css — styles for layout and look
- scripts/main.js — small script to handle the Buy modal

How to use:
1. Edit prices, descriptions, and checkout links in index.html and scripts/main.js.
2. Host this as a static site (GitHub Pages, Netlify, Vercel, or any static host).

Customize:
- Replace the placeholder checkoutUrlFor() implementation in scripts/main.js with your real purchase links.
- Update server IP and branding in index.html.
